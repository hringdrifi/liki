# Liki

Pocket HIDとしてAndroidスマホをBluetooth HIDのキーボード兼マウスにするアプリです。PCへの常駐ソフトは不要です。

## 動作条件

- Android 9（API 28）以上で、端末が `BluetoothHidDevice` に対応していること
- Bluetooth HIDホストとしてペアリングできるPC（Windows、macOS、Linuxなど）
- Androidはアプリが前面から外れるとHID登録を解除する場合があります。ホームからアプリへ戻ったとき、前回接続していたPCへの再接続を一度試みます。

## 使い方

1. Android端末でアプリを起動し、Bluetooth接続とBluetooth公開の権限を許可します。
2. 接続画面で「ペアリング待機」を押します。
3. PCのBluetooth設定からスマホを探し、双方に表示されるペアリング要求を承認します。
4. 接続画面で「更新」を押してPCを選び、「選択したPCに接続」を押します。接続中は同じボタンからキャンセルできます。次回は前回接続したPCが初期選択されます。PC側から接続される場合もあります。
5. 接続後はキーボード画面に切り替わります。右端中央の細い印から左へスワイプすると、レイアウト選択・表示のリセット・設定・切断のメニューが開きます。

トラックパッドを使う場合は、右端メニューの「レイアウトを選択」から添付のGhostedレイアウトを選びます。

設定画面では、画面の向きを自動・縦向き・横向きから選べます。「画面を常にON」にするとLikiを開いている間は自動消灯しません。「タッチ時に振動」は初期状態ではオフで、オンにするとキーのタップとトラックパッドのクリック時に振動します。キーピッチは概算値を確認し、3.0〜24.0 mmの手動設定ができます。自動で画面に収めた場合もキーの大きさは向きを変えても維持され、メニューの「表示をリセット」を押すと現在の向きでキーボード全体が画面に収まる大きさへ戻ります。修飾キーの保持、長押しでのキー割り当て、ピンチ拡大縮小、トラックパッドのタップクリック・長押しドラッグ・2本指スクロールも個別に切り替えられます。ポインターの速度とスクロール速度は0.5〜3.0倍で調整でき、スクロール方向も反転できます。設定は端末内に保存されます。

トラックパッドの「カーソルの送信間隔」は即時（毎回送信）・16ms（送信多め）・32ms（標準）を選べます。初期値は32msです。ポインターの速度を変えずに、カーソルの引っ掛かりや応答の違いを比べられます。

## KLEキーボード

右端メニューの「レイアウトを選択」から、添付のGhostedレイアウト、標準キーボード、ファイル読み込みを選べます。ファイル読み込みでは [Keyboard Layout Editor](https://www.keyboard-layout-editor.com/) の **Download JSON** で保存した `.json` を選びます。KLEの行、空白、キーの幅・高さ、色、回転とラベルを反映します。KLEの「Raw Data」欄からコピーした省略記法は厳密なJSONではないため、ファイルに保存するときは Download JSON を使ってください。

画面上のキーをタップするとHIDキーを送ります。Ctrl、Shift、Alt、Win/Cmdはタップすると次のキーまで保持されます。キーを長押しするとHIDキーの割り当てを変更できます。ラベルから推測できないキーは枠が赤く表示され、長押しで割り当てが必要です。レイアウトと割り当ては端末内に保存されます。

2本指で拡大縮小、1本指ドラッグでキーボードを移動できます。設定で「ドラッグでキーボードを移動」をオフにすると、通常キーをドラッグしても表示位置は変わりません。「表示をリセット」で表示倍率と位置を戻します。横向きの画面ではフルサイズのレイアウトを操作しやすくなります。

KLEの `g: true`（Ghosted）に指定したキー領域は、キーボード画面内のトラックパッドになります。その領域では1本指移動、タップ、ダブルタップ後のドラッグ、長押しドラッグ、2本指タップで右クリック、2本指スクロール、ピンチズーム、3本指タップで中クリックを使えます。ピンチズームはPCへCtrl＋ホイールとして送るため、対応する画面で動作します。Ghosted領域から始めた操作はキーボード表示のパンやズームに使われません。`g: false` で後続キーを通常キーへ戻せます。

KLEはキーの表示・配置形式であり、HIDコードを直接指定しません。自動割り当ては一般的なUS配列のラベルに対応します。PC側の配列が異なると記号などの出力が変わります。日本語などのUnicode文字はHIDキーコードに一対一で対応しません。

接続できないときは、両機器のペアリングを解除してからアプリを開いた状態で再ペアリングしてください。端末メーカーがHID Deviceプロファイルを提供していない場合、このアプリでは利用できません。

## ビルド

Android Studioでこのディレクトリを開き、Android SDK Platform 34を導入して `app` をビルドします。コマンドラインでは `./gradlew assembleDebug`（Windowsは `gradlew.bat assembleDebug`）です。生成されるAPKは `app/build/outputs/apk/debug/app-debug.apk` です。

Android 12以降ではBluetooth接続・公開の実行時権限を要求します。探索権限や位置情報権限は不要です。
