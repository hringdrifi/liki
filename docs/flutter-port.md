# Flutter 移植の確認メモ

基点: main `2c2f3f4`。過去の共有UIブランチは取り込んでいない。

## 構成

- Flutter: 接続画面、右端メニュー、設定、レイアウト選択、割り当て編集、キーボード描画、全タッチ操作、4レイヤーの状態。
- Kotlin: Android Bluetooth HID、権限、端末公開、ファイル選択、KLE/キー名の解析、既存の SharedPreferences とバインディングの移行。
- Native View を埋め込む構成ではなく、キーボードは Flutter の CustomPainter と PointerEvent で描画・操作する。
- `layout` と `settings` の保存先、名前付きレイアウトのJSON、表示位置の物理ピクセル単位を維持する。画面再生成時のレイヤー・編集ドラフト・表示位置は Android の savedInstanceState に保持する。
- HID のレポート定義・送信キュー・送信間隔と、標準KLE・キー割り当ての内容は main の実装を使用する。

## 自動テスト

`cd flutter` で `flutter analyze` と `flutter test` を実行する。

テストは Android との境界を模擬し、修飾キー、全4レイヤー、ワンショット、押している間のレイヤー、Consumerレポート、編集の保存と破棄、名前付き保存と復元、読めないインポートでの状態維持、回転キーのヒット判定、タッチジェスチャー、縦横の画面レイアウトを確認する。実際の Bluetooth 転送の保証には実機確認が必要。

## 実機での照合項目

- ペアリング公開、PCの選択、接続・キャンセル・切断、復帰時の一度だけの再接続。
- 通常キー、左右修飾式、メディアキー、L0〜L3、トグル・循環・ワンショット・押している間の切り替え。
- Ghosted領域の移動、クリック、ダブルタップドラッグ、長押し、2本指タップ/スクロール/ピンチ、3本指タップ。
- KLEファイル読み込み、標準レイアウトへの切り替え、名前付き保存・上書き・復元・削除。
- 編集の保存とキャンセル、ベースの継承、自動割り当て、修飾キー式の組み立て。
- 全設定、画面回転、表示リセット、右端メニュー、全画面とシステムジェスチャー。
- 既存版と同じ署名で更新した場合の設定・保存レイアウトの引き継ぎ。

このブランチのライセンスは AGPL-3.0-or-later。iOS 向け HID と iOS 実機検証は含まない。
